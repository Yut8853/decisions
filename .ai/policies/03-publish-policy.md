# Publication policy

1. AI never pushes directly to `main`.
2. Default AI output is `content/drafts/**`.
3. Live publication requires `AI_ALLOW_PUBLISH=true`, passing Reviewer, Fact Checker, Publisher Gate, CI and branch protection.
4. Existing Decision and Evidence ids cannot be overwritten automatically.
5. Measured benchmark files are accepted only when generated by the repository benchmark runner and validated by checksum schema.
6. Auto-merge is disabled by default and requires the `ai-approved` label plus repository variable `ENABLE_AI_AUTOMERGE=true`.
7. Human accountability remains with the repository owner even when generation and review are automated.
