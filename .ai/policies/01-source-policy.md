# Source policy

1. Current technical facts must be based on direct primary sources whenever available.
2. Secondary articles may discover a question or field report, but cannot establish current API support by themselves.
3. Every Evidence object needs a precise `claim`, direct URL, source name, verification status and date.
4. Conflicting sources are recorded; they are not averaged into a confident answer.
5. Source access failure changes Evidence to needs-review and may trigger Decision review.
