# Contributing

Corrections and counterexamples are welcome through Issues or Pull Requests.

Before opening a PR:

```bash
pnpm install
pnpm check
```

For factual changes, include a direct source and explain exactly which Claim it supports. For performance claims, include reproducible code and environment. Do not submit hand-written files under `content/benchmarks/results`.

The project may reject technically valid code when the resulting Recommendation is insufficiently evidenced or too broad.
